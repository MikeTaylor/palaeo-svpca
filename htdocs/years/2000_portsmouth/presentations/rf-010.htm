The aspect of the use of cladistics which causes me most concern is the notion that it is the only valid way of determining phylogentic relationships - a 'quasi-religious' attitude. Cladistics is a way of analysing a set of characters. Texts on the method make it very clear that a cladogram is not a phylogentic tree - it is a chart showing the relationships between characters in a set of characters. Yet, cladograms are usually treated as phylogenies without applying any of the further analyses - for homoplasy, for example - which can show how confidently the tree can be used as a phylogeny.
